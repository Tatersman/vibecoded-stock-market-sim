# Market Lab

A responsive paper trading website built with JavaScript and Vite.

## Development

Requires Node.js 20.19+ or 22.12+ (validated on Node 24).

```sh
npm ci
npm run dev
```

If the default npm cache is unavailable, use `npm ci --cache /workspace/.npm-cache`.

```sh
npm run build
npm run preview
```

Start with $100,000 in virtual cash. Select a stock, buy or sell whole shares, and review holdings and order history. Account data stays in this browser's local storage. Prices are fixed simulation inputs; chart trends are illustrative, not historical market data. No API keys, backend, or real trades are involved.
